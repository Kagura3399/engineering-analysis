# Engineering Analysis Portfolio

整理本人於大學期間所進行之工程分析與程式設計成果，
主要以Python將工程數學、矩陣運算與結構分析相關理論轉化為可執行程式，
藉由程式化計算加深對工程分析方法與數值運算流程的理解。

本作品集亦作為研究所推甄之工程程式能力與自主學習成果展示。

---

## About This Repository

本作品集目前主要包含：

- 工程數學與矩陣運算
- 座標轉換
- 齊次座標矩陣
- 結構分析

並練習將複雜計算流程拆解為可重複執行的程式。

## Project Contents

### Direct Stiffness Method

直接勁度法為結構分析中常用的矩陣分析方法之一。

透過 Python 建立相關矩陣運算流程，
將結構元素之局部座標系統、座標轉換與整體勁度矩陣等概念進行程式化處理。

相關內容包括：

- 座標轉換
- 齊次座標矩陣
- 4 × 4 矩陣運算
- 元素矩陣推導
- 工程數值計算
